# Design Your Workspace — monis.rent

Interactive workspace builder for [monis.rent](https://www.monis.rent): pick a desk, a chair, and accessories, watch an illustrated preview update live, then rent the setup.

**Live:** https://desent-coding-test-2-beryl.vercel.app

## Development

```bash
pnpm install
pnpm dev
```

- `pnpm lint` — Biome check
- `pnpm build` — production build
